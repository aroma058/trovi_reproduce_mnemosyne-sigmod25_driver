# trovi_reproduce_mnemosyne-sigmod25

This repository reproduces some results of the Mnemosyne SIGMOD 2025 artifact: https://github.com/BU-DiSC/Mnemosyne

Paper: *Mnemosyne: Dynamic Workload-Aware BF Tuning via Accurate Statistics in LSM trees*, Zichen Zhu, Yanpeng Wei, Ju Hyoung Mun, Manos Athanassoulis. SIGMOD 2025. https://doi.org/10.1145/3725327

The notebook `Exp.ipynb` reproduces Figure 4 on Chameleon Cloud, using the fork at https://github.com/aroma058/trovi_reproduce_mnemosyne-sigmod25-fork

This may contain some modifications related to experiment reproduction, environment setup, and artifact packaging. All original implementation credit belongs to the original authors.
